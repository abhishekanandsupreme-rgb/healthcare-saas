# Issue Tracker

This repo uses **local markdown** as its issue tracker.

Issues are tracked as markdown files under `.scratch/` in this repo.

## Workflow

- Create a new issue by adding a markdown file under `.scratch/<feature-or-area>/`.
- Use the existing engineering skills (`to-tickets`, `triage`, `to-spec`) to read from and write to this tracker.

## Notes

- No external service is required.
- Good for solo projects or repos without a remote.
- Switch to GitHub Issues later if the repo gets a remote and team collaboration increases.
